# 爆款标题六招（3D 地图短视频版）

六招：**贴标签、设悬念、造冲突、做留白、送好处、借势**。一个标题叠 2–3 招最好，叠多了像标题党。

| 招 | 做法 | 3D 地图片例子 |
|---|---|---|
| 贴标签 | 标题里出现目标人群/城市身份词 | 「台州人举手 这个台你念对了吗」 |
| 设悬念 | 只说一半，用为什么/到底/原来 | 「郑州这两条铁路 为什么是歪的」 |
| 造冲突 | 反常识、对比、站队 | 「被骂千年的昏君 修了条今天还在跑船的河」 |
| 做留白 | 半截判断，正文必须交代清楚 | 「少修一条河 他会是千古一帝吗」 |
| 送好处 | 明说观众能拿到什么（一张图看懂/清单） | 「一张 3D 图看懂泄洪区在哪」 |
| 借势 | 热点事件、热词、大城市名直接进标题 | 热点后 0–7 天发「X 在地图上意味着什么」 |

## 硬规则
- 长标题 ≤20 字；**视频号短标题 6–16 字，不用逗号，用空格断句，不用「」【】等符号**（平台会吞或显示异常）。
- 只用有出处的事实和数字；不承诺收益、不用违禁词、不造谣。标题承诺什么，片子就兑现什么。
- 每条出 5–8 个备选，标出用了哪几招，推荐 1 个并写理由。

## 自检
≤20 字？用了哪几招？有具体地名或数字吗？短标题有没有逗号或「」【】？片子能兑现吗？
