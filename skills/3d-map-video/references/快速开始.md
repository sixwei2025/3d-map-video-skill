# 3D 地图短视频 Skill · 5 分钟上手

把本目录整个放进你的 agent 的 skills 目录（WorkBuddy / Codex / Claude Code 等支持 `SKILL.md` 的都行），然后对 agent 说：
「用 3d-map-short-video skill，给 <城市/战役> 做一条 3D 地图短视频」。agent 会按 `SKILL.md` 的 7 步走。

## 1. 依赖
| 依赖 | 版本 | 用途 |
|---|---|---|
| Node.js | ≥ 18 | 跑 `puppeteer-core` 驱动 Chrome 逐帧截图 |
| Google Chrome / Chromium | 近期稳定版 | 无头渲染 WebGL 地图（Mac 走 Metal 硬件加速；Linux 无 GPU 时走 SwiftShader，慢很多） |
| ffmpeg + ffprobe | 带 libx264 | 编码、混音、封面、交付 |
| Python 3 | ≥ 3.9，`numpy`、`Pillow` | 编译 episode、混音、实拍层、封面 |
| MapLibre GL JS | 已内置 `engine/vendor/`（BSD-3-Clause） | 三维地图引擎 |
| 字体 Noto Sans SC | 已内置（SIL OFL 1.1） | 字幕/标签 |

```bash
npm install && bash scripts/fetch_music.sh && pip3 install numpy pillow && bash scripts/doctor.sh
```

## 2. 跑通示例（先出 1 秒小样）
```bash
python3 engine/compile.py episodes/demo_city.json          # 生成 work/v2/demo_city/
ID=demo_city MODE=sample SAMPLE="0-30" PAR=1 bash scripts/run_all.sh
# 小样：out/demo_city/sample_0_30.mp4
```
完整示例 `episodes/taizhou_v1.json`（城市）和 `episodes/war_jingxing_v1.json`（战争史）可直接编译、渲染画面；要出带声音的成片，需要你自己的配音 `work/v2/<id>/audio/voice.wav`（本包不含任何配音）；台州的实拍图需按 `examples/城市-台州/发布包.txt` 里列的来源自行下载到 `projects/taizhou_v1/broll/`。

## 3. 做你自己的一条
1. 写脚本：`templates/脚本模板.md`（五段式）+ `templates/sources模板.md`
2. 配音 → `work/v2/<id>/audio/voice.wav` + 每句时间轴
3. 复制 `templates/episode-最小示例.json` 为 `episodes/<id>.json`，换数据和文案
4. `ID=<id> MODE=sample bash scripts/run_all.sh` 看小样 → `ID=<id> nohup bash scripts/run_all.sh >/dev/null 2>&1 &` 出全片
5. `python3 scripts/selfcheck.py <id>`，按 `templates/发布包模板.md` 写发布包

速度参考：Apple Silicon Mac（Metal，4 个 Chrome 并行）2 分钟片约 1 小时上下；无 GPU 的 Linux 服务器约 5–30 帧/分钟/进程，2 分钟片要数小时【待你自己实测】。首次渲染要下载瓦片，先跑预取（run_all 默认开）。

## 4. 数据源与许可（务必读）
| 数据 | 默认来源 | 许可 / 状态 |
|---|---|---|
| 卫星影像 | Esri World Imagery（`server.arcgisonline.com`，免登录端点） | **商用授权【待核实】**：Esri 免认证端点一般被认为仅供其客户/测试；商用发布建议申请 ArcGIS Location Platform key 或换有授权的影像源（天地图需申请 key，许可【待核实】；Sentinel-2 cloudless 各年份许可不同【待核实】）。episode 里 `"imagery"` 字段可换成任意 XYZ 瓦片地址。 |
| 地形 DEM | AWS Terrain Tiles（Terrarium，`s3.amazonaws.com/elevation-tiles-prod`） | 免 key 公开数据集，由多来源 DEM 合成，需按其说明署名；具体署名要求【待核实】 |
| 河流/城市注记 | Natural Earth（公有领域）；部分河道吸附 OpenStreetMap | OSM 为 ODbL，需署名「© OpenStreetMap contributors」 |
| 配乐 | `assets/music/`：War Theme (ver 2) / Spring Spring；Determined Pursuit / Emma_MA | CC0 1.0，来源页见 `assets/music/*_theme.json` |
| 国界/省界底数据 | `engine/data/100000.min.json`、`610000.min.json`（阿里云 DataV.GeoAtlas，GCJ-02） | 许可与完整性（含南海诸岛）【待核实】；模板默认不画，仅供调试 |
| 中国地图合规 | — | 默认不画国界、省界；涉及国界的画面按《地图管理条例》使用标准地图或送审，短视频具体适用【待核实】 |

画面右上角来源注记由 episode 的 `credit` 字段控制，请如实填写。

## 5. 目录
```
SKILL.md                 agent 读的主流程（7 步）
references/快速开始.md   本文件
已知坑和经验.md
engine/                  引擎（compile.py / scene.html / render*.mjs / mix_theme.py / broll.py / cover_poster.py / deliver_hq.sh …）
  data/ vendor/          地理底数据、MapLibre、字体
assets/music/            两首系列主题曲 + 授权登记
scripts/                 run_all.sh（一条命令全链）、selfcheck.py、doctor.sh、launch.py（可选后台启动器）
episodes/                可直接编译的 episode（demo_city / taizhou_v1 / war_jingxing_v1）
templates/               episode 示例、脚本、sources、发布包、复盘模板
references/               选题五审+五段式、爆款标题六招、对标拆解精简版
examples/                台州（城市）、井陉之战（战争史）：脚本、出处表、时间轴、build_episode、发布包；样张/ 引擎直出帧
```
